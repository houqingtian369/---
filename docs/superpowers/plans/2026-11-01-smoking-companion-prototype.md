# 松口气戒烟陪伴原型实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将已确认的戒烟陪伴方案落成可点击的网页样板，覆盖日常进度、SOS 求助、逐次成功记录、吸烟记录、奖励目标与戒烟路线。

**Architecture:** 沿用现有 Vanilla JavaScript 单页结构，所有演示记录存入浏览器 localStorage。`app.js` 负责状态、计算与交互，`styles.css` 负责响应式界面；不新增依赖。

**Tech Stack:** HTML、CSS、原生 JavaScript、localStorage。

**Spec:** 本任务中用户确认的「松口气」戒烟陪伴方案与本地现有网页原型。

## Global Constraints

- 每次成功应对的实际支数由用户输入并累计，不根据日均烟量推算。
- 单次吸烟记录重启本轮计时，历史无烟打卡与成功应对记录保留。
- 未确认的日期不自动计作无烟日或吸烟日。
- 提醒设置在网页样板中只保存偏好，不发送通知。
- 保留纯静态网页和本机浏览器存储，不增加服务端或依赖。

## Review Focus

- 同一日可有多次成功应对；次数按事件数计算，支数按实际数量求和。
- 跨午夜记录应按本地日期计入对应日期。
- 当天已有吸烟记录时，不能再提交当天无烟打卡。
- 未来戒烟日期、尚未记录的日期不显示为已完成。
- 页面切换或重新打开时，计时显示应从已保存时间正确恢复。
