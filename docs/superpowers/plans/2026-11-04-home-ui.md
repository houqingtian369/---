# 松口气首页 UI 实施计划

**Goal:** 用 UI/UX Pro Max 的习惯追踪与移动端建议重做现有首页，并展示浏览器效果。

**Architecture:** 沿用原生 JavaScript 渲染、现有事件绑定和 localStorage 数据。首页样式放在 home.css，以 home-ui 作用域限定；不引入依赖。

**Tech Stack:** HTML、CSS、JavaScript。

**Spec:** 用户要求先查看页面、提出配色排版与交互方案，再修改并展示。

## 设计决定

- 采用松针绿、暖白、杏色，保留用户已选择的页面底色。
- 首页顺序为无烟进度、求助、今日成就、打卡、本周记录和吸烟记录。
- 大数字突出连续无烟天数；轻量植物 SVG 作为装饰，不承载医疗含义。
- 沿用真实记录、未来计划、今日已打卡/吸烟等状态与事件处理。
- 手机单列、桌面双列，触控区域至少 44px，支持减弱动画。
